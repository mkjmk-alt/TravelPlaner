# 일차별 가까운 순 정렬

웹의 내 일정 화면에서 각 일차 오른쪽 **가까운 순 정렬**을 누른다. 미리보기에서 방문 순서와 기존·정렬 후 직선 거리 합계를 확인하고 **이 순서로 적용**을 선택한다. 취소하거나 Escape를 누르면 일정 데이터를 변경하지 않는다. 적용한 순서는 기존 저장·동기화 경로에 기록되고 지도 화살표에도 반영된다. 일정 화면의 기존 **실행 취소** 기능으로 직전 상태를 복원할 수 있다. 실행 취소 이력은 현재 실행 세션에서만 유지된다.

## 정렬 기준과 제한

- 첫 장소를 출발점으로 고정한다. 식사 일정을 기준으로 오전·오후처럼 구간을 나눈 뒤 각 구간에서 현재 장소에 가장 가까운 미방문 장소를 차례로 선택한다. 식사 전후의 장소가 서로 넘어가지 않으며 식사는 기존 시간에 유지한다.
- 좌표 간 구면 거리(Haversine)를 사용한다. 실제 도로 거리나 최단 전체 동선을 보장하지 않는다. 미리보기에서 전체 거리가 늘어나는 경우도 별도로 안내한다.
- 정렬 계산 자체는 외부 지도 API를 호출하지 않는다. 지도 표시가 실제 길 모드라면 변경된 방문 순서에 따라 기존 경로 표시 기능이 길찾기를 다시 요청할 수 있다.
- 위치 정보가 있는 장소가 3개 미만이면 변경할 순서가 없어 적용하지 않는다. 첫 장소의 위치 정보가 없으면 위치가 있는 출발 장소를 먼저 맨 앞으로 옮기도록 안내한다.
- 위치가 없는 일정은 해당 배열 자리에 그대로 둔다. 위치 없는 항목은 거리 계산에서 제외한다. 동일 거리의 장소와 중복 좌표는 기존 순서를 우선한다.
- 선택한 일차만 변경한다. 예비 목록, 다른 일차, 지출·기록 데이터는 변경하지 않는다. 읽기 전용 공유 일정에는 정렬 버튼을 표시하지 않는다.

## 시간 및 저장 순서

기존 시간대를 시간 칸으로 유지하고 방문 장소만 재배치한다. 예를 들어 09:00 호텔·10:00 먼 관광지·11:00 가까운 관광지라면 09:00 호텔·10:00 가까운 관광지·11:00 먼 관광지로 바뀐다. 이동 시간을 새로 계산하거나 새로운 시간을 만들지 않는다. 예약 정보·메모·장소 식별자는 해당 장소와 함께 유지된다.

이전 거리 정렬로 시간이 뒤섞인 일차는 출발점 이후 위치와 올바른 시간 정보가 있는 일정을 저장된 시간순으로 복원한 뒤 정렬한다. 첫 장소, 위치 없는 항목과 시간 미지정 칸은 기존 자리를 유지한다. 식사는 복원된 시간 기준 자리에 고정한다. 미리보기에서 복원 안내와 식사 고정 표시를 확인할 수 있다.

정렬을 적용한 일차에 `orderMode: 'distance'`를 저장하여 이후 일정 편집·장소 추가·예비 목록 이동·일괄 이동 시 순서가 저절로 되돌아가지 않도록 한다. 새로 들어오는 장소는 끝에 추가하고 필요하면 다시 가까운 순 정렬을 실행한다. 거리 정렬 일차의 수동 위·아래 이동도 시간 칸은 유지하고 장소만 이동한다. 미리보기 중 해당 일차가 수정되거나 삭제되면 적용을 막고 새 미리보기를 만들도록 안내한다.

## 아이콘과 카테고리

일정 추가 시 선택한 아이콘과 카테고리를 함께 저장한다. 식사·카페·항공·숙박·관광·쇼핑·교통·액티비티·행사·기타로 분류하며 선택한 카테고리를 추가 창에 표시한다. 예비 목록에 추가할 때도 동일하게 저장된다.

`category: 'meal'`인 항목은 자동 정렬에서 고정한다. 기존 `food`·식사·식비 카테고리와 카테고리 없이 식사 아이콘(🍽️)만 저장된 일정도 식사로 인식한다. 카페는 별도 카테고리이며 자동 고정하지 않는다. 장소명만으로 식사를 추측하지 않는다.

## 일정 지도 이미지 저장

지도 우측의 이미지 저장 아이콘을 누르면 현재 지도 범위의 PNG 미리보기를 연다. **PNG 저장**으로 파일을 저장하거나, 파일 공유를 지원하는 브라우저에서는 **공유**로 기기 공유 화면을 연다. 일차별 지도·전체 일정·예비 목록에서 현재 표시한 마커와 직선 또는 실제 길 경로를 그대로 담는다. 필요한 범위로 지도를 조정한 뒤 저장한다.

검색창·앱 메뉴·장소 추가 창은 이미지에 포함하지 않으며 Google 로고·출처 표기는 유지한다. 지도 이미지 변환 라이브러리는 저장을 누를 때만 불러온다. PNG는 최대 한 변 2048px·300만 픽셀 이내로 제한하여 모바일 메모리 부담을 줄인다. 지도 로딩 오류나 이미지 복사 실패 시 안내를 표시하고 빈 이미지를 다운로드하지 않는다. 별도의 Static Maps API를 호출하지 않는다.

## 검증 범위

자동 테스트는 가까운 순 선택, 첫 장소 유지, 위치 없는 항목·0도 좌표·날짜 변경선, 중복 좌표, 날짜별 적용·오래된 미리보기 차단, 시간 칸 유지·이전 정렬의 시간 복원·식사 구간 고정, 아이콘별 카테고리 저장, 수동 이동, 미리보기 적용·취소와 지도 이미지 크기 제한을 확인한다.

기존 정렬 화면의 브라우저 검증은 320·430·768·1440px 화면에서 미리보기 배치, 키보드 열기·Escape·포커스 복원, 적용·실행 취소, 재접속 후 순서, 일정 편집·예비 장소 추가를 확인했다. 짧은 화면의 긴 미리보기는 목록만 스크롤하고 하단 적용 버튼을 유지한다.

시간·식사·이미지 저장 추가 검증은 430·1440px 화면에서 로컬 빌드와 격리된 테스트 여행을 사용했다. 정렬 후 저장된 시간 칸·식사 예약 유지, 식사 아이콘의 카테고리 저장, 실제 Google 지도 타일·경로 화살표·번호 마커·로고·출처가 포함된 PNG 다운로드와 중앙 미리보기를 확인했다. 실제 계정·클라우드 데이터는 수정하지 않았다. 실제 길찾기 API 호출과 iPhone·Android 기기의 공유·파일 저장은 이 검증에 포함하지 않았다.
