# 일차별 가까운 순 정렬

웹의 내 일정 화면에서 각 일차 오른쪽 **가까운 순 정렬**을 누른다. 미리보기에서 방문 순서와 기존·정렬 후 직선 거리 합계를 확인하고 **이 순서로 적용**을 선택한다. 취소하거나 Escape를 누르면 일정 데이터를 변경하지 않는다. 적용한 순서는 기존 저장·동기화 경로에 기록되고 지도 화살표에도 반영된다. 일정 화면의 기존 **실행 취소** 기능으로 직전 상태를 복원할 수 있다. 실행 취소 이력은 현재 실행 세션에서만 유지된다.

## 정렬 기준과 제한

- 첫 장소를 출발점으로 고정한다. 이후 현재 장소에서 가장 가까운 미방문 장소를 순서대로 선택한다.
- 좌표 간 구면 거리(Haversine)를 사용한다. 실제 도로 거리나 최단 전체 동선을 보장하지 않는다. 미리보기에서 전체 거리가 늘어나는 경우도 별도로 안내한다.
- 정렬 계산 자체는 외부 지도 API를 호출하지 않는다. 지도 표시가 실제 길 모드라면 변경된 방문 순서에 따라 기존 경로 표시 기능이 길찾기를 다시 요청할 수 있다.
- 위치 정보가 있는 장소가 3개 미만이면 변경할 순서가 없어 적용하지 않는다. 첫 장소의 위치 정보가 없으면 위치가 있는 출발 장소를 먼저 맨 앞으로 옮기도록 안내한다.
- 위치가 없는 일정은 해당 배열 자리에 그대로 둔다. 위치 없는 항목은 거리 계산에서 제외한다. 동일 거리의 장소와 중복 좌표는 기존 순서를 우선한다.
- 선택한 일차만 변경한다. 예비 목록, 다른 일차, 지출·기록 데이터는 변경하지 않는다. 읽기 전용 공유 일정에는 정렬 버튼을 표시하지 않는다.

## 시간 및 저장 순서

도착 시간·예약 정보·메모·장소 식별자는 그대로 유지한다. 정렬 이후 시간이 역순일 수 있으므로 기존 시간 확인 안내를 함께 제공한다. 정렬을 적용한 일차에 `orderMode: 'distance'`를 저장하여 이후 일정 편집·장소 추가·예비 목록 이동·일괄 이동 시 시간순으로 되돌아가지 않도록 한다. 새로 들어오는 장소는 끝에 추가하고 필요하면 다시 가까운 순 정렬을 실행한다.

기존의 시간순 정렬을 사용하는 일차는 동작을 유지한다. 거리 정렬 일차에서 수동 위·아래 이동은 장소 순서만 변경하고 시간을 맞바꾸지 않는다. 미리보기 중 해당 일차가 수정되거나 삭제되면 적용을 막고 새 미리보기를 만들도록 안내한다.

## 검증 범위

자동 테스트는 가까운 순 선택, 첫 장소 유지, 위치 없는 항목·0도 좌표·날짜 변경선, 중복 좌표, 날짜별 적용·오래된 미리보기 차단, 시간순 정렬과 거리순 유지, 수동 이동, 미리보기 적용·취소를 확인한다.

실제 웹 컴포넌트를 구동한 브라우저 검증은 320·430·768·1440px 화면에서 미리보기 배치, 키보드 열기·Escape·포커스 복원, 적용·실행 취소, 재접속 후 순서, 일정 편집·예비 장소 추가를 확인한다. 짧은 화면의 긴 미리보기는 목록만 스크롤하고 하단 적용 버튼을 유지한다. 브라우저 검증은 로컬 테스트 데이터로 실행하며 계정·클라우드·실제 지도 API 호출은 포함하지 않는다.
