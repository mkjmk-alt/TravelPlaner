TravelPlaner 개인정보처리방침

시행일: 2026년 9월 1일

TravelPlaner는 여행 일정, 예약 정보, 체크리스트, 예산과 지출을 관리하는 서비스입니다. 사용자가 로그인하지 않은 경우 입력한 여행 데이터는 사용 중인 브라우저 또는 앱의 로컬 저장소에 보관됩니다.

수집 및 이용하는 정보

로그인을 선택한 경우 이메일 주소, 인증 식별자와 사용자가 저장한 여행 데이터가 계정 동기화를 위해 처리될 수 있습니다. 현재 위치 기능을 선택한 경우 위치 정보는 지도에서 현재 위치를 표시하는 용도로만 사용됩니다.

외부 서비스

지도와 장소 검색에는 Google Maps Platform이 사용될 수 있으며, 로그인과 데이터 동기화에는 Supabase가 사용됩니다. 각 서비스에는 해당 제공자의 개인정보처리방침이 적용됩니다.

데이터 보관과 삭제

로그인하지 않은 로컬 데이터는 앱 삭제, 브라우저 사이트 데이터 삭제 또는 기기 설정의 앱 데이터 삭제 시 제거됩니다. 로그인한 사용자는 앱에서 데이터를 삭제하거나 계정 관련 지원을 요청할 수 있습니다.

권한

위치 권한은 현재 위치 기능을 사용할 때 요청합니다. 파일 접근은 사용자가 백업을 가져오거나 내보낼 파일을 직접 선택할 때만 사용합니다.

문의
