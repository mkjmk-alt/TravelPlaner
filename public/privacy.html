TravelPlaner 개인정보처리방침

시행일: 2026년 9월 2일

TravelPlaner는 여행 일정, 예약 메모, 체크리스트, 예산과 지출을 관리하는 서비스입니다. 이 방침은 웹앱과 iOS·Android 앱에 적용됩니다.

1. 기기에만 저장되는 정보

로그인하지 않고 공유 기능도 사용하지 않으면 여행 일정, 즐겨찾기, 예약 메모, 체크리스트, 예산과 지출은 사용 중인 브라우저 또는 앱의 로컬 저장소에만 보관됩니다. JSON 백업, iCalendar, CSV와 통계 이미지는 사용자가 선택한 기기 위치에 저장되며 TravelPlaner 서버로 자동 업로드되지 않습니다.

2. 선택 기능을 사용할 때 처리되는 정보

  • 선택적 계정: 이메일 주소와 계정 식별자는 회원가입, 로그인, 동기화와 계정 관리에 사용됩니다.
  • 선택적 동기화: 여행 일정, 장소, 예약 메모, 체크리스트, 예산·지출과 즐겨찾기가 계정과 연결되어 저장될 수 있습니다.
  • 공유 일정: 사용자가 공유를 실행한 여행 사본이 서버에 저장됩니다. 링크를 가진 사람은 해당 사본을 보고 수정할 수 있으므로 민감한 정보를 포함하지 않아야 합니다.
  • 지도와 장소 검색: 검색어, 지도 화면의 위치와 선택한 장소 정보가 지도·장소 검색 결과 제공을 위해 Google Maps Platform으로 전송될 수 있습니다.
  • 현재 위치: 사용자가 현재 위치 버튼을 누르고 권한을 허용한 경우 정확한 위치를 지도에 표시하는 동안 사용합니다. TravelPlaner는 현재 위치를 계정 데이터나 여행 기록으로 자동 저장하지 않습니다.
  • 기술 요청 정보: IP 주소, 브라우저·기기 정보와 요청 시각이 서비스 제공, 보안과 장애 대응 과정에서 호스팅 사업자에 의해 제한적으로 처리될 수 있습니다.

3. 처리 목적

정보는 사용자가 요청한 앱 기능 제공, 계정 인증·관리, 기기 간 동기화, 공유 일정 제공, 보안 유지와 오류 대응을 위해서만 처리합니다. 광고, 사용자 추적, 데이터 판매 또는 타사 맞춤 광고에는 사용하지 않습니다.

4. 서비스 제공자

  • Supabase: 선택적 인증, 계정 데이터와 동기화·공유 데이터 저장
  • Cloudflare: 웹 콘텐츠와 API 제공, 보안 및 네트워크 처리
  • Google Maps Platform: 지도 표시, 장소 검색과 길찾기
  • ExchangeRate-API: 환율 조회

외부 지도 앱이나 예약 링크를 사용자가 직접 열면 해당 서비스의 개인정보처리방침이 적용됩니다.

5. 보관과 삭제

  • 로컬 데이터는 사용자가 직접 삭제하거나 앱·브라우저 데이터를 지울 때까지 기기에 남습니다.
  • 계정 동기화 데이터는 계정이 유지되는 동안 보관되며 앱 안의 계정 삭제 기능으로 인증 계정과 함께 삭제할 수 있습니다.
  • 공유 일정은 생성자가 공유 해제를 실행할 때 삭제됩니다. 로그인한 사용자의 공유 일정은 계정 삭제 시에도 함께 삭제됩니다.
  • 사용자가 내보낸 백업 파일은 TravelPlaner가 삭제할 수 없으므로 파일을 저장한 기기나 클라우드에서 직접 관리해야 합니다.

계정과 데이터 삭제 방법은 계정 및 데이터 삭제 페이지에서 확인할 수 있습니다.

6. 보안

전송 구간에는 HTTPS를 사용하고, 공유 관리 토큰은 원문이 아닌 단방향 해시로 서버에 저장합니다. 로그인하지 않은 앱 데이터가 사용자 동의 없이 운영체제 클라우드 백업에 포함되지 않도록 네이티브 앱의 자동 백업을 비활성화합니다.

7. 권한과 선택권

위치 권한은 현재 위치 기능을 실행할 때만 요청하며 거부해도 일정·예산 등 다른 기능을 사용할 수 있습니다. 파일 접근은 사용자가 백업 파일을 가져오거나 저장 위치를 선택할 때만 사용합니다. 계정과 동기화, 공유 기능도 선택 사항입니다.

8. 아동

TravelPlaner는 아동을 대상으로 설계된 서비스가 아니며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

9. 방침 변경과 문의

처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신합니다. 개인정보 문의는 TravelPlaner 지원 페이지를 이용해주세요. 비밀번호, 인증 코드 또는 공개하면 안 되는 예약번호를 문의 내용에 포함하지 마세요.
